# Manhunt Quest

A spooky, humorous browser-based manHunt game built with Python, Flask and HTML.

## What is Manhunt Quest?

You've been hired to track down a slippery criminal known only as Johnny. A charming, good-for-nothing rogue who has vanished into the Forest. Your mission is to find him, catch him and bring him to justice.
It is imperative to know that the forest doesn't give up its secrets easily, hence you will need to solve puzzles, crack codes and outsmart the forest itself to get to Johnny.

## How to Play

* Enter the forest
* Solve 3 spooky puzzles across the Shadow Path, Whispering Trail and Trail of Bones
* Unlock the Secret Chamber
* Restore the shattered treasure map
* Crack the secret code
* Catch Johnny. Finally.

## Built With
 Python 3, Flask, HTML & CSS, JavaScript, GitHub, Deployed on Render
